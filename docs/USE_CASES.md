# Use Cases

This guide walks you through 8 real-world scenarios utilizing LocalLLM's diverse AI personas.

## 1. Analyze a vendor proposal
**Persona:** Solutions Architect
**Workflow:**
1. Upload the PDF of the vendor proposal using the Document tool.
2. Select the `solutions-architect` persona.
3. Prompt: *"Analyze this vendor proposal for our new cloud infrastructure. Highlight any potential scalability bottlenecks, hidden costs, and compare their architectural approach against AWS best practices."*

## 2. Plan a storage migration
**Persona:** Storage Engineer
**Workflow:**
1. Select the `storage-engineer` persona.
2. Prompt: *"Create a detailed, step-by-step migration plan to move 50TB of block storage from our legacy SAN to a new all-flash array. Include pre-migration checks, the sync process, cutover procedures, and a rollback plan. Assume a VMware environment."*

## 3. Prepare a QBR
**Persona:** Technical Account Manager (TAM)
**Workflow:**
1. Upload the CSV of the client's usage metrics for the past quarter.
2. Select the `tam` persona.
3. Prompt: *"Based on this usage data, prepare an executive summary for our upcoming Quarterly Business Review with Acme Corp. Highlight key adoption metrics, identify areas where they can improve efficiency, and suggest two new features they should adopt next quarter."*

## 4. Review code for vulnerabilities
**Persona:** Security Analyst
**Workflow:**
1. Paste the source code or use the Local File Manager tool to point to the repository.
2. Select the `security-analyst` persona.
3. Prompt: *"Review this authentication middleware for security vulnerabilities. Look specifically for OWASP Top 10 issues, such as injection flaws, broken authentication, and sensitive data exposure. Provide actionable remediation steps."*

## 5. Restructure a messy document
**Persona:** Document Processor
**Workflow:**
1. Paste the raw, unstructured OCR text or messy meeting notes.
2. Select the `document-processor` persona.
3. Prompt: *"Take this raw OCR text and restructure it into a clean, well-formatted Markdown document. Use appropriate headings, bullet points, and tables where data is presented."*

## 6. Create a project plan
**Persona:** Project Manager
**Workflow:**
1. Select the `project-manager` persona.
2. Prompt: *"Create a 4-week Agile sprint plan for developing a new mobile app onboarding flow. Include specific epics, user stories with acceptance criteria, and identify critical path dependencies."*

## 7. Generate architecture from requirements
**Persona:** Solutions Architect
**Workflow:**
1. Select the `solutions-architect` persona.
2. Prompt: *"Design a microservices architecture for a high-traffic e-commerce platform. Requirements: handles 10k orders/minute, uses event-driven communication, and ensures high availability. Provide a Mermaid diagram of the architecture and explain the technology choices for each service."*

## 8. Write API documentation
**Persona:** Technical Writer
**Workflow:**
1. Provide the JSON schema or source code for the API endpoint.
2. Select the `technical-writer` persona.
3. Prompt: *"Write comprehensive API documentation for this endpoint. Include a description, HTTP method, authentication requirements, path/query parameters, request body schema, and example responses for success (200) and error (4xx/5xx) states."*
