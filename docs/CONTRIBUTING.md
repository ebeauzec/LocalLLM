# Contributing to LocalLLM

Thank you for your interest in contributing to LocalLLM! Please review the following guidelines before submitting your contributions.

## Code of Conduct

We are committed to providing a welcoming and inspiring community for all. Please be respectful and professional in all interactions.

## How to Report Bugs

1. Check the [Troubleshooting Guide](TROUBLESHOOTING.md) first.
2. Search existing issues to see if it has already been reported.
3. Open a new issue providing:
   - OS version and hardware specs
   - LocalLLM version
   - Steps to reproduce
   - Diagnostic logs (`localllm logs --export`)

## How to Request Features

1. Search existing feature requests.
2. Open a new issue with the label `enhancement`.
3. Clearly describe the feature, the problem it solves, and potential use cases.

## Pull Request Process

1. Fork the repository.
2. Create a feature branch (`git checkout -b feature/amazing-feature`).
3. Make your changes following the coding standards.
4. Test your changes thoroughly.
5. Commit your changes (`git commit -m 'Add amazing feature'`).
6. Push to the branch (`git push origin feature/amazing-feature`).
7. Open a Pull Request against the `main` branch.

## Coding Standards

- **PowerShell**: Follow standard PowerShell styling conventions. Use descriptive variables and include Help headers for all functions.
- **Docker**: Keep images lean. Pin dependencies to specific versions.
- **Markdown**: Use standard Markdown syntax. Include appropriate headings, lists, and code blocks.

Due to the proprietary nature of this project, **all contributors must sign a Contributor License Agreement (CLA) before their pull request can be merged.**

By submitting a Pull Request, you agree that:
1. You assign all copyright and intellectual property rights in your contribution to the project owner (Eugene Beauzec).
2. Your contribution is your original work.
3. You have the right to submit the work and grant the required rights.

Instructions for signing the CLA will be provided automatically on your first Pull Request via a bot comment.
